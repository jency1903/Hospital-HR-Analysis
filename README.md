# 🏥 Hospital HR Analysis Dashboard

## Overview
A Power BI dashboard analyzing hospital staff HR metrics — job satisfaction, salary, promotion eligibility, and patient feedback across departments, shifts, and job roles. Built to support hospital HR teams in workforce planning and staff wellbeing tracking.

## 📊 Key Insights & Visuals
- **Job Satisfaction by Department** – satisfaction levels across departments
- **Promotion Eligibility** – share of staff eligible for promotion
- **Salary for Month Based on Rating** – pay trends by appraisal rating
- **Job_Satisfaction by Appraisal Rating** – satisfaction vs. performance rating
- **Department Feedback**, **Gender Wise Feedback**, **Job Role**, **Shift** breakdowns
- KPI cards: Total Staff, Average Salary, Average Experience, Average Performance, Average Attendance
- Slicers: Department, Gender, Shift, Job Role

## 🗂️ Data Fields
Department, Job_Role, Shift, Gender, Monthly_Salary, Appraisal_Rating, Job_Satisfaction, Promotion_Eligible, Patient_Feedback_Score

## 🛠️ Tools Used
- Power BI Desktop
- DAX measures (Average Salary, Average Experience, Average Performance, Total Staff, etc.)
- Power Query for data shaping

## 🚀 How to Use
1. Download `Hospital_HR_Analysis.pbix`.
2. Open in [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free).
3. Use slicers to filter by department, gender, shift, or job role.
4. Click on any visual to cross-filter the page.
